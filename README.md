AJA LEY — Boutique e-commerce
 

 
FOR EVERY MOOD. EVERY YOU.

 

AJA LEY est une boutique de mode féminine proposant des robes, ensembles, abayas et tenues de cérémonie.

 

Ce projet consiste à développer une plateforme e-commerce permettant de présenter les produits AJA LEY, de faciliter les commandes et de centraliser le parcours client, tout en conservant WhatsApp comme moyen privilégié de confirmation pour certaines commandes, notamment les commandes internationales.

 
 
📌 Contexte du projet
 

AJA LEY est une activité de vente de vêtements féminins qui fonctionne notamment via Instagram et WhatsApp.

 

Avant la mise en place de cette plateforme, les clientes pouvaient découvrir les produits sur les réseaux sociaux puis contacter directement la boutique pour obtenir des informations, vérifier la disponibilité ou passer commande.

 

Le site a pour objectif de rendre ce fonctionnement plus simple et plus professionnel en proposant :

 
·	un catalogue en ligne ;
·	des fiches produits détaillées ;
·	la gestion des tailles et longueurs ;
·	un panier ;
·	un parcours de commande ;
·	le calcul des frais de livraison au Sénégal ;
·	la gestion des commandes ;
·	un espace client ;
·	un espace d'administration ;
·	une confirmation par WhatsApp pour les commandes internationales.

 

Le projet est également réalisé dans un contexte académique par deux étudiants, tout en étant conçu pour pouvoir servir de base au véritable site e-commerce de la boutique.

 

 
🎯 Objectifs
 

Les principaux objectifs du projet sont :

 
·	présenter les produits AJA LEY de manière claire et élégante ;
·	permettre aux clientes de consulter les produits disponibles ;
·	faciliter le choix de la taille et de la longueur ;
·	permettre la création d'un panier ;
·	permettre aux clientes de commander avec ou sans compte ;
·	calculer automatiquement les frais de livraison selon la zone ;
·	permettre aux clientes de consulter leurs commandes ;
·	faciliter la gestion des produits et des commandes depuis l'administration Django ;
·	gérer les promotions directement depuis les produits ;
·	proposer un parcours spécifique pour les commandes internationales ;
·	conserver WhatsApp comme moyen de confirmation pour les commandes internationales.

 

 
✨ Fonctionnalités
 
🛍️ Catalogue
 

Le site permet de consulter les différents produits disponibles chez AJA LEY.

 

Chaque produit peut présenter :

 
·	son nom ;
·	ses images ;
·	sa catégorie ;
·	son prix ;
·	sa disponibilité ;
·	ses tailles disponibles ;
·	les longueurs disponibles lorsque cela est nécessaire ;
·	une éventuelle promotion.

 

Les produits peuvent être classés par catégories telles que :

 
·	Robes ;
·	Ensembles ;
·	Abayas ;
·	autres catégories selon les besoins de la boutique.

 

 
⭐ Meilleures ventes
 

La page d'accueil présente une sélection manuelle de produits considérés comme les meilleures ventes.

 

Cette sélection permet notamment de mettre en avant certaines pièces appréciées par les clientes.

 
 
🆕 Nouveautés
 

Une section dédiée aux nouveautés permet de mettre en avant les produits récemment ajoutés au catalogue.

 

Les nouveaux produits disposent de leurs propres images et informations.

 
 
🔥 Promotions
 

Les promotions sont gérées directement au niveau des produits.

 

Pour un produit, il est possible de :

 
·	activer ou désactiver une promotion ;
·	définir un prix promotionnel ;
·	conserver le prix normal ;
·	calculer automatiquement le pourcentage de réduction.

 

Lorsqu'une promotion est active, elle peut être affichée dans :

 
·	le catalogue ;
·	la fiche produit ;
·	le panier ;
·	le récapitulatif de commande ;
·	les informations transmises via WhatsApp.

 

La rubrique Promotions du menu est affichée lorsqu'il existe des promotions actives.

 

 
📏 Gestion des tailles
 

Le site utilise des tailles standards :

 
·	XS
·	S
·	M
·	L
·	XL
·	XXL

 

Pour certains produits, la cliente peut également sélectionner une longueur souhaitée :

 
·	1m55
·	1m60
·	1m65
·	1m70
·	1m75
·	1m80
·	1m85
·	1m90

 

Les informations de taille et de longueur sont conservées avec les articles du panier et de la commande.

 

 
📐 Guide des tailles
 

Un guide des tailles est disponible afin d'aider les clientes à choisir leur taille.

 

Les mensurations sont indiquées en centimètres.

 

| Taille | Poitrine | Taille | Hanches |

|--------|----------|--------|---------|

| XS | 70–78 cm | 60–66 cm | 85–90 cm |

| S | 80–84 cm | 68–70 cm | 90–95 cm |

| M | 90–92 cm | 72–77 cm | 98–100 cm |

| L | 98–100 cm | 80–85 cm | 113–115 cm |

| XL | 115–120 cm | 90–95 cm | 120–125 cm |

| XXL | 120–125 cm | 100–115 cm | 130–135 cm |

 

Le guide explique également comment mesurer :

 
·	la poitrine ;
·	la taille ;
·	les hanches ;
·	la longueur souhaitée.

 

 
🛒 Panier
 

La cliente peut ajouter plusieurs produits au panier.

 

Pour chaque article, le panier conserve notamment :

 
·	le produit ;
·	la quantité ;
·	la taille ;
·	la longueur lorsqu'elle est sélectionnée ;
·	le prix applicable ;
·	la promotion éventuelle.

 

La cliente peut ensuite :

 
·	modifier les quantités ;
·	modifier les options ;
·	supprimer un article ;
·	consulter le sous-total ;
·	consulter les frais de livraison ;
·	consulter le total de la commande.

 

 
📦 Commandes
 

Le site permet de créer une commande directement depuis le panier.

 

Les clientes peuvent commander :

 
·	avec un compte ;
·	sans créer de compte.

 

Les utilisateurs possédant un compte peuvent consulter leur historique de commandes.

 

Chaque commande possède un numéro unique au format :

 
#AJL-00042  
Les commandes peuvent avoir différents statuts :  
- En attente  
- Confirmée  
- En préparation  
- Expédiée  
- Livrée  
- Annulée

## **🌍 Commandes internationales**  
Les commandes internationales sont également prises en charge.  
Pour une commande internationale :  
- la cliente peut préparer sa commande directement sur le site ;  
- les frais de livraison sont indiqués comme **À confirmer** ;  
- le montant exact de la livraison internationale est déterminé en fonction de la destination ;  
- la confirmation finale se fait via WhatsApp.  
Un bouton permet d'ouvrir WhatsApp avec les informations principales de la commande afin de faciliter la confirmation.

## **💳 Paiement**  
Dans cette version du projet, aucune API de paiement réelle n'est intégrée.  
Le choix a été fait de conserver un fonctionnement simple et adapté au contexte actuel de la boutique.  
Les paiements en ligne via des services tels que Wave ou Orange Money pourront être intégrés dans une future version du projet.  
### **Version actuelle**  
Commande sur le site  
        ↓  
Validation de la commande  
        ↓  
Confirmation avec la boutique  
        ↓  
Paiement selon les modalités convenues  
### **Évolution prévue**  
Une future version pourra intégrer directement :  
- Wave ;  
- Orange Money ;  
- d'autres moyens de paiement en ligne.
